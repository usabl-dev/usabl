# Contributing to usabl

usabl is not accepting pull requests yet. The maintainer is taking the project to a
stable point first. A pull request from outside the project will be closed without
review.

You can still help:

- **Report a bug.** Use the
  [bug report form](https://github.com/usabl-dev/usabl/issues/new?template=bug_report.yml).
  A wrong verdict, a missing gap, or a confusing message counts as a bug.
- **Request a feature.** Use the
  [feature request form](https://github.com/usabl-dev/usabl/issues/new?template=feature_request.yml),
  and describe the problem before the solution.
- **Ask a question or give feedback.** Use the
  [question form](https://github.com/usabl-dev/usabl/issues/new?template=question.yml).
- **Report a security problem privately.** Do not open an issue. Follow
  [SECURITY.md](SECURITY.md).

Contributions will open later. This file will say when.

## Rules for everyone

- Everyone who takes part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
- usabl is licensed under [Apache-2.0](LICENSE).

## How this project is developed

These documents describe how the maintainer develops usabl. They are published so the
process is open to read. They are not an invitation to send pull requests.

- **By hand:** [docs/guides/make-a-contribution.md](docs/guides/make-a-contribution.md)
  covers setup, the commands to run, the trust-critical paths, and what review checks.
- **With an AI coding agent:** [AGENTS.md](AGENTS.md) holds the rules that Codex,
  Cursor, Copilot, Claude Code, and other agents read in this repository.

Every change is reviewed and approved by the maintainer, @eparenti, who is the only
code owner. CI must pass before a change can merge.
