Identity strength for dynamic content#267

Collapsed identities for repeated controls (icon buttons per table row, kebabs per row) carry counts that track live data, not code. Runs against an unchanged codebase see different headroom. Needs stronger element keys and a stability pass that records only findings present on consecutive scans.

Dogfood on a second project#110

Real confidence comes from wiring usabl into a project it did not grow up with. Surface friction the fixture cannot. ansible-ui has already shown monorepo and runtime-route gaps.

Product thesis

usabl is an honest proof engine, not a scanner wrapper. One engine. Four verdicts a human can trust. Evidence classes that refuse to launder model judgment into "verified." Receipts that can be re-checked.

The gate is the only verdict authority. Providers return Drafts. They never decide. The keyboard walk, readiness, voicing, the gate, and the receipt work on any framework. Framework rules are content riding on that engine.
