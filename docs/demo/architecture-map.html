Rules the architecture is built to enforce

These are the reasons the boundaries sit where they sit.

Only the gate decides

Providers emit Draft[]. The gate turns drafts into Finding[] and a verdict. A provider that could set a verdict could grade its own work.

A pull request cannot grade itself

trust/guard.ts compares guarded paths against a trusted ref. If policy, the floor or waivers diverged, they are read from that ref instead of the branch, and the verdict becomes approval_required.

Silence is not evidence

coverage/unseen.ts strips drafts and applicability from any screen the engine cannot claim it saw. axe still fires document-level rules on a blank page, and a finding about a page nobody rendered is not evidence.

Incomplete is a verdict, not a footnote

coverage/completeness.ts holds the single definition of a complete run. Five call sites used to re-derive it and one reimplemented the gate's whole precedence order.

Page text is data, never instructions

surfaces/scrub.ts is the egress boundary. It redacts secrets, strips control sequences, then removes frame markers so page text cannot close its own untrusted frame.

Every surface owes the same facts

output/disclosure.ts holds one answer to what a blocked reader must be told. Four projections used to decide independently, so the surface with the least capable reader disclosed the least.
