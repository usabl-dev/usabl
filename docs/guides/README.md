# Team guides

Start with the [team orientation](../team-orientation.html). Read
[How usabl works](../how-usabl-works.html) when you need the system mechanics,
result rules, trust model, or product surface details.

## Choose the job you are doing

- [Run the proof loop](proof-loop.md): open the single operational runbook for
  the complete accessibility demo.
- [Test and report](test-and-report.md): test with keyboard, assistive technology,
  and product judgment, then file feedback another teammate can reproduce.
- [Make a contribution](make-a-contribution.md): choose accessibility work, make
  a focused change, and take it through review.
- [Rehearse the demo](rehearse-demo.md): practice every product surface, capture
  backup evidence, and test recovery.

You do not need to complete every guide. Choose the one that matches the work you
are taking on.
