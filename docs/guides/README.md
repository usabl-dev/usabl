# Guides

Start with the [usabl walkthrough](../usabl-walkthrough.html). Read
[How usabl works](../how-usabl-works.html) when you need the system mechanics,
result rules, trust model, or product surface details. Read the
[code walkthrough](../code-walkthrough.html) when you want to read the source and
choose one of the eight systems to work on.

## Choose the job you are doing

- [Run the proof loop](proof-loop.md): break, check, repair, and verify one
  accessibility barrier on the sample app.
- [Test and report](test-and-report.md): test with keyboard, assistive technology,
  and product judgment, then file a report that someone else can reproduce.
- [How sensitive is usabl](how-sensitive-is-usabl.md): put declared defects on pages and
  see which ones the checks catch, with `usabl verify sensitivity`.
- [Check the built page against the design](design-input.md): turn the accessibility
  stamps in a Figma file into requirements, and check them on the built page.
- [Set up the CI gate](ci-gate.md): what `usabl install --ci` writes and fills in, and
  the steps it leaves to you.
- [How usabl is developed](make-a-contribution.md): setup, commands, and review
  rules for changes to usabl. The project is not accepting outside pull requests yet.

You do not need to complete every guide. Choose the one that matches the work you
are taking on.
